# Source beside its ranked file: isolated presentation experiment

Production remains the restored frozen policy. The
[mechanism-first query candidate](query-framing-study.md) is a rejected experimental
parent, not a new incumbent. This experiment changes only how that parent's
already-selected evidence is arranged in stdout. It does not change discovery,
classification, thresholds, source selection, source budgets or the skill.

## No-model prerequisite

The failed parent's complete Django packet is 350,468 bytes, with 212 files and
96 source blocks. A generic rearrangement places each file's existing blocks
immediately after its ranked path/role/reading-lead entry. It preserves every
nonblank line with multiplicity, all numbered source lines including blank source
lines, ranked file order, and all evidence. The resulting packet is also 350,468
bytes. Only unnumbered section separator placement may differ.

SQLite's first source moves from byte 61,232 to 480. Its relevant condition moves
from byte 69,342 to 8,590. The serialized prefix through that condition is 8,891
characters, versus 39,831 characters before the actual retained outer-tool
truncation marker. This demonstrates earlier placement within that observed
prefix allowance; it is not a universal tokenizer or tool-limit guarantee.
Contract, deterministic script, candidate text and proof are retained at
`/tmp/jg-presentation-counterfactual/`. No model calls were made.

The failed solver later read and explicitly recognized the condition, then
replaced its failing same-type regression with a type-changing scenario. Initial
visibility is therefore only a plausible contributor, not an established cause
of failure. This presentation experiment may fail to change that decision.
