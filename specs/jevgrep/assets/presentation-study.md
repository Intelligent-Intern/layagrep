# Source beside its ranked file: isolated presentation experiment

Production remains the restored frozen policy. The
[mechanism-first query candidate](query-framing-study.md) is a rejected experimental
parent, not a new incumbent. This experiment changes only how that parent's
already-selected evidence is arranged in stdout. It does not change discovery,
classification, thresholds, source selection, source budgets or the skill.

## No-model prerequisite

The failed parent's complete Django packet is 350,468 bytes, with 212 files and
96 source blocks. A generic rearrangement places each file's existing blocks
immediately after its ranked path/role/reading-lead entry. It preserves every
nonblank line with multiplicity, all numbered source lines including blank source
lines, ranked file order, and all evidence. The resulting packet is also 350,468
bytes. Only unnumbered section separator placement may differ.

SQLite's first source moves from byte 61,232 to 480. Its relevant condition moves
from byte 69,342 to 8,590. The serialized prefix through that condition is 8,891
characters, versus 39,831 characters before the actual retained outer-tool
truncation marker. This demonstrates earlier placement within that observed
prefix allowance; it is not a universal tokenizer or tool-limit guarantee.
Contract, deterministic script, candidate text and proof are retained at
`/tmp/jg-presentation-counterfactual/`. No model calls were made.

The failed solver later read and explicitly recognized the condition, then
replaced its failing same-type regression with a type-changing scenario. Initial
visibility is therefore only a plausible contributor, not an established cause
of failure. This presentation experiment may fail to change that decision.

## Retained failed result

Full Sol cost is **$0.398754 across 21 generations**, versus the fixed $1.5055472
baseline. It is not a cost win because the patch fails the required alteration
behavior. Jev has 3,550 client calls and 3,541 priced responses, with known
observed subtotal **$1.131532920**; the full total is unknown and excluded.

The exact query was:

> How are database column attributes propagated when relationship fields derive their database type from referenced fields, and where is this behavior tested?

Retrieval ran for 702.456 seconds before Sol sent Ctrl-C, explicitly because of
the 900-second task budget. The harness did not time out. The CLI returned exit
130 and an explicitly incomplete packet: 213 files, 159 source blocks and 242,840
bytes. SQLite ranked 35 with no selected excerpt or lead; neither its path nor
its guard survived tool truncation. First-ranked ForeignKey source did survive.
This different selection does not test the offline counterfactual's old packet.

The additional pass made 1,352 recorded requests, each carrying the same 26
evidence items across 13 paths: 44,730 source bytes, 49,017 compact JSON bytes.
That is below the unchanged 64,000-byte feedback threshold. The agent then
changed only ForeignKey metadata propagation and passed 13 field tests; it did
not test actual database alteration or inspect SQLite afterward. It finished at
770.921 seconds, leaving 129 seconds unused. Clock pressure is a demonstrated
reason for retrieval cancellation, not proof it alone caused the narrow patch.

The inner tool clipped 60,710 estimated tokens to 30,000, and the outer wrapper
then clipped its serialized result to 10,000. Query, ranking, selection, feedback
execution, cancellation and effective tool allowance all differ from the parent.
No causal formatting benefit is established. Detailed trace/visibility evidence:
`/tmp/jg-adjacent-source-django-comparison/`. The candidate remains experimental.
The [future timing protocol](timing-protocol.md) addresses the unintended
wall-clock criterion prospectively; this failed result is never rescored.
