# Original brief and feedback

The request and corrections that produced the first launch video (for a
repository-research CLI). Treat the brief as the quality bar; treat each
correction as a failure mode to avoid on the first pass next time.

## Brief (verbatim)

> Make a dynamic 30-second motion graphics video that shows what an incredible
> motion designer you are, like it's your showreel for a résumé. go all out.
> Make it a video to introduce this cli. talk about its purpose, have visuals for
> how it works behind the scenes (it's a technical audience), highlight the use
> of jev & systemone models as fast & efficient research agents, and highlight
> the 40% cheaper result for when it's used with codex on swebench, where codex
> is prompted to use it as an independent researhc agent. Must have music and
> motion must match the music Do it like a real professional production video,
> not like a demo or prototype. Add more animation and motion design; avoid using
> screenshots as raw; instead, break them down into components/icons so we can
> animate those too. Make the motions more juicy. Use the best motion design
> techniques you can.

## Feedback, in order

1. **Preview showed a near-empty frame.** The upload preview on X showed the
   cold open's first sparse frames. Tell: the thumbnail is blank or nearly blank.
2. **A single poster frame at frame 0 was not enough.** X still showed a frame a
   few frames in. Tell: a one-frame poster is skipped; the thumbnail needs a hold.
3. **Dark poster before a light opening.** Asked for the same tan background so
   there is no flash when playback starts.
4. **Preferred the product in action as the preview.** Chose the reveal frame
   (logo, tagline, terminal with a finished command and its output) over the
   benchmark key art. The key art stays useful as a README image.
5. **Keep the source.** The render project belongs in the repo, not a scratch
   directory. The user had it committed and pushed straight to main.

## What landed well

The user kept the overall direction: a problem cold open, a beat drop into the
logo reveal, a dark behind-the-scenes section built from animated icons, a slam
on the benchmark number with its disclosure intact, and a lockup with the
install command.
